# Jogos de Patrício Paulo

Downloads dos meus jogos feitos no Godot. O código-fonte fica em repositórios privados; aqui ficam só os arquivos para jogar.

Baixe pela página [Releases](../../releases/latest) ou pelo meu site: https://patricio-paulo-portfolio.vercel.app/#jogos

| Jogo | Plataforma | Arquivo |
| --- | --- | --- |
| Cobra | Windows | `Cobra-Windows.zip` |
| Cobra | Android | `Cobra-Android.apk` |
| Cruzeiro: Modo Zumbis | Windows | `Cruzeiro-Windows.zip` |

## Como instalar

- **Windows:** extraia o .zip e dê dois cliques no `.exe`. Se aparecer "O Windows protegeu o computador", clique em "Mais informações" e depois em "Executar assim mesmo" (o aviso aparece porque o jogo não tem assinatura paga).
- **Android:** abra o `.apk` no celular e permita a instalação de "fontes desconhecidas" quando o Android pedir.
